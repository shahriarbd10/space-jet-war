# Assets

**Art direction:** Voidline Command is a high-contrast neo-futurist aerospace-instrumentation game style. Gameplay takes place in a near-black blue tactical void, where cyan indicates player systems and confirmed hits, amber signals power, and red identifies threats. All art should remain sharply readable at arcade-play scale.
